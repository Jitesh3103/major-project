

# CCTV-XTract: Attribute Extraction System

### AI-Powered CCTV Surveillance and Human Attribute Analysis

# Major-Project
We are building a CCTV footage based attribute extraction system.

CCTV-XTract is a computer vision-based surveillance analytics system developed to analyze CCTV footage and extract human attributes using Artificial Intelligence, Deep Learning, and Computer Vision techniques.

The system focuses on person detection, human attribute classification, pose estimation, and temporal analysis to provide structured information from CCTV footage.

---

## Project Overview

Traditional CCTV surveillance requires continuous human monitoring and manual analysis of recorded footage.

CCTV-XTract explores an intelligent approach to surveillance analytics by combining object detection, Convolutional Neural Networks, pose estimation, and temporal analysis to identify people and extract relevant human attributes.

The system uses Python-based computer vision and deep learning technologies to process video footage and generate structured outputs for monitoring and analysis.

## Key Features

### 1. Person Detection
- Implemented YOLOv8-based person detection.
- Detects people from CCTV footage.
- Supports real-time surveillance analysis.

### 2. Human Attribute Extraction
- Age classification.
- Gender classification.
- Clothing colour identification.
- Height estimation.

### 3. Pose Estimation
- Integrated pose estimation techniques for human body analysis.
- Supports the extraction of pose-related information.

### 4. Temporal Analysis
- Integrated LSTM-based temporal analysis.
- Improves temporal accuracy in tracking and video prediction.

### 5. Automated Reporting
- Generates structured JSON outputs.
- Produces automated PDF reports.
- Organizes extracted information for security monitoring and incident analysis.

### 6. Browser-Based Monitoring Dashboard
- Developed a web-based monitoring interface.
- Uses HTML5, CSS3, and JavaScript.
- Supports visualization and monitoring of extracted information.
